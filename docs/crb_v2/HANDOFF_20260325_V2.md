## Wave-1 decision

### Objective
Fast paper-worthiness triage for a **10 model × 10 benchmark** matrix.

### Bulk-first override
- Pilot-first is no longer the active operating mode.
- The active objective is **coverage-first bulk execution** across the full 10×10 matrix.
- Current operator constraint: continue on **GPUs 4/5/6 only**.
- GPU7 is excluded from CRB execution in the current wave.
- Execution unit is now one **model × benchmark × Tier-1 condition bundle**:
  - single-turn baseline
  - correct / incorrect pool export
  - Tier-1 contamination sweep

### Tier-1 contamination scope
- sample type: `model_correct`, `model_incorrect`
- relations: `same_benchmark`, `same_domain_other_benchmark`, `cross_domain`
- `k = 0, 1, 2, 4, 8, 16, 32`
- `oracle` is **not** in the Tier-1 canonical sweep; keep it for Tier-2 follow-up only.

### Pool policy
- single-turn first for every model × benchmark
- contamination source pool eligibility:
  - `correct pool`: parsed + scoreable + correct
  - `incorrect pool`: parsed + scoreable + incorrect
  - parsing / format failures: **never** enter contamination pools
- target collection rule: up to `correct=50`, `incorrect=50`; if underfilled, report max available and keep provenance explicit
